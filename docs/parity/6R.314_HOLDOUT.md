# 6R.314 — Post-milestone generalization holdouts

Baseline: `43d7db4e`. The frozen witness `20:29455649 T/TGTTTG` stays closed.
`HOLDOUT_6R243` was not run. Production behavior of the four 6R.310–6R.312
and 6R.303 semantics was not changed.

These holdouts use the existing env-gated synthetic contract tests. There is
no Java trim, order, or likelihood dump for an interval other than the closed
canonical witness, so the checks compare production Rust with the GATK 4.4
formulas on other inputs. They do not reopen graph assembly, PairHMM, or PL
conversion.

## Holdouts

| Holdout | First checkpoint | Result |
| --- | --- | --- |
| STR | tandem unit and trim span | `STR_HOLDOUT_PASS` |
| Failed mate | predicate, then evidence keys | `FAILED_MATE_HOLDOUT_PASS` |
| Read order | comparator field, then clip identity | `READ_ORDER_HOLDOUT_PASS` |

| Composite `chrHold:4500 G>GCAG` | trim geometry | `COMPOSITE_HOLDOUT_PASS` |

STR cases are on `chrHold` around position 4000: unit length 1 and greater
than 1, insertion and deletion, an alternate that extends the repeat, anchor
exclusion, a non-STR indel, a SNP, and an insertion with no tandem. None is
`A>AT` with counts `[8, 9]`.

Failed-mate keeps unpaired reads, unmapped reads, unmapped mates, and
same-contig mates. A different-contig mapped mate is the only key removed.
Low MAPQ and a short read are not mate-fail keys. The zero-row checkpoint lives in the lib suite and always runs. It
scores one haplotype: the cross-contig read has no likelihood row, and a read
absent from the pre-filter originals still receives `0.0` cells.

Read order ties nine reads at one clipped start. `java_read_coordinate_compare`
and `clip_finalized_reads_in_place` agree. Identity permutation: yes.
Positional differences: 0. The pre-6R.312 name sort still places
`aaa-reverse` first; production does not.

Jacobian probes are diff 0, below 8, equal to 8, above 8, one table step, and
a half step. Equal arguments add `log10(2)`. Diff at least 8 returns the
larger argument unchanged. Homozygote genotype likelihoods stay the allele
likelihoods. The heterozygote matches the Java pair formula. On
`[-1.0, -1.00015]` that heterozygote is not the analytic `log10_sum_log10`.

The composite stops at trim, then mate membership, then clipped order, then
genotype likelihoods. It does not emit the canonical PL vector.

Cumulative 6R gates: 187. The 182 gates through 6R.312 are unchanged. These
five PASS holdouts add one gate each.
