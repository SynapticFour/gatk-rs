1//! GATK-RS HaplotypeCaller Library
2//! This crate contains the HaplotypeCaller implementation for GATK-RS.
3//! # Public API surface
4//! Default features expose the **HC engine / product** API used by `gatk-cli`
5//! (run/engine/region/assembly/genotyping/PairHMM/VCF emit). Internal parity TSV
6//! exporters require the `dev-dumps` feature (off by default; enabled via
7//! `gatk-cli` and `parity_harness`). P12 fixture tables and discovery/compat
8//! helpers are crate-private unless `parity_harness` is enabled (integration
9//! tests + the `hc_full_parity_gate` example).
10#![allow(clippy::result_large_err)]
11// Without `parity_harness`, P12/compat/dump scaffolding stays compiled but unwired
12// into the product path — suppress that dead-code noise. CI uses `--all-features`.
13#![cfg_attr(not(feature = "parity_harness"), allow(dead_code, unused_imports))]
14
