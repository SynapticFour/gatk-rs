1//! Per-locus pileup snapshots attached to assembly regions (GAP-B-07 / B.5.8).
2
3/// One locus pileup retained on an [`crate::assembly_region_iterator::AssemblyRegion`]
4/// when pileup tracking is enabled (GATK `AlignmentAndReferenceContext`).
5/// # Invariants
6/// `depth` is the pileup read count at `pos` on `contig`.
7/// `pos` is 1-based reference coordinate matching iterator pileup keys.
8/// # Ownership
9/// Owns contig name; stored in region-side pileup vectors when tracking is on.
10/// # Mutation
11/// Immutable snapshot attached to an assembly region after iterator emission.
12/// # Biological assumptions
13/// Sparse pileup depth summaries support RCM/activity diagnostics without full per-read pileup retention.
14/// # Java equivalence
15/// GATK `shouldTrackPileupsForAssemblyRegions` / `AlignmentAndReferenceContext` pileup attachment.
16#[derive(Debug, Clone, PartialEq, Eq)]
17pub struct RegionPileupLocus {
18    pub contig: String,
19    pub pos: u64,
20    pub depth: usize,
21}
