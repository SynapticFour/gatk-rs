Module java_hc_site_semantics 

Source
Expand description

Java HC cluster/site predicates (De-P12 generalization). Compatibility layer (crate::compatibility): band/motif semantics for P12-interval Java parity (waivers W-H1 / W-H3). Not genome-wide HC. Allele-pattern and band-based semantics replace coordinate-pinned is_p12_* gates in production genotyping, emit, and RCM paths. Harness comparison oracle (is_java_diff_oracle_allele) remains in read_event_discovery for baseline gates only.
