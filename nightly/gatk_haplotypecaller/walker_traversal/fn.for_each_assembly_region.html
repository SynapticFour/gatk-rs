Expand description

Stream assembly regions shard-by-shard, invoking on_region as each region is finalized.

Unlike collect_assembly_regions / into_assembly_regions, this does not retain prior regions (and their owned BAM record clones) for the whole interval — peak memory stays near one shard’s all_records plus the in-flight region(s) the callback holds.

Peak-RSS: clears the iterator’s previous-region Arc pin before the callback so finalizeRegion can into_unique without a second deep BAM copy, then commits the region’s reads afterward for GATK overlap reuse on the next fill.
