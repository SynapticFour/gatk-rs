Module pairhmm 

Source
Expand description

PairHMM likelihood scaffold. This module provides a deterministic log10-space PairHMM with: explicit Match/Insertion/Deletion state transitions, base + mapping quality integration via effective quality capping, numerically stable log-sum transitions.
