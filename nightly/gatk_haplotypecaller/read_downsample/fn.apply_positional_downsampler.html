Filter records in coordinate order like GATK PositionalDownsampler on a sorted stream. With header: Some, enforces ReadCoordinateComparator.compareCoordinates monotonicity (no cmp == 1) and uses coordinate-based run boundaries. With None, falls back to pos-only grouping (unit tests).
