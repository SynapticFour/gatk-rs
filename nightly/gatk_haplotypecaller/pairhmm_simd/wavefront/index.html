Architecture C phase-1: row-wavefront Logless PairHMM.

Rolling 2-row DP with optional AVX2/NEON column striping for Match/Insertion. Deletion stays serial (left-cell dependence). f32 primary + f64 retry. Scalar crate::pairhmm_logless remains the correctness oracle.

Opt-in via super::dispatch::PairHmmImpl::Wavefront — not wired into FASTEST_AVAILABLE until gates pass.
