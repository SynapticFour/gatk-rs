SIMD / pairs-in-lanes Logless PairHMM (runtime feature dispatch). Parallelization axis: independent haplotypes in SIMD lanes for one shared read (Endeavor-style), not GKL anti-diagonal striping. Scalar crate::pairhmm_logless remains the correctness reference.
