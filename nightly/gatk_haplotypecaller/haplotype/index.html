GATK Haplotype representation for assembly output.

§Invariants (assembly result lists)

Exactly one haplotype should be marked is_reference before genotyping filters run. sort_haplotypes_assembly_result_order: non-reference haplotypes by descending score (base-sequence tie-break), reference last. When present, genome_loc uses 1-based inclusive coordinates (GenomeLoc).
