Module region_vcf_emit 

Source
Expand description

Emit VCF variant records from a call_region outcome (production path). Applies crate::hc_emit_policy gates, optional HC site annotations, and (harness-only) Java FORMAT overlay via crate::p12_java_format_fixup. Default CLI emission does not require oracle TSV files. See docs/ARCHITECTURE.md stage 11.
