Module bio_ids 

Source
Expand description

Strongly typed biological identifiers for HaplotypeCaller. These newtypes exist to make domain mix-ups a compile error: haplotype index vs PL genotype index, 1-based genome locus vs pad-relative offset, MAPQ score vs SAM unavailable (255), etc. Prefer explicit constructors (new / try_new) over blanket From integer conversions. Convert at BAM/VCF wire edges only.
