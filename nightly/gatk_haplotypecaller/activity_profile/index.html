GATK-aligned activity profile scaffolding (Phase 4, step 51). Mirrors the data model and numeric thresholds from GATK’s org.broadinstitute.hellbender.utils.activityprofile package and AssemblyRegionArgumentCollection defaults used by BandPassActivityProfile.
