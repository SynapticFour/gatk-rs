GATK AlleleFilteringHC.filterAlleles slice — drop weak haplotypes before genotyping. Java ranks haplotypes using per-allele getAlleleLikelihoodVsInverse (HC genotyping GL vs inverse allele). Rust uses that score when PairHMM rows exist, else read-LL sum fallback.
