Module shared_bam 

Source
Expand description

Arc-backed BAM records shared between the shard read cache and assembly regions. Shared BAM records for shard/region ownership without deep clones.

§Observable contract

Same read evidence as owned bam::Record lists (qname/pos/flags/bases/cigar). Ownership only — not a downsampler.

§Mutation

Callers that rewrite CIGAR/bases/MAPQ must use record_make_mut / BamRecordSlot::make_mut.
