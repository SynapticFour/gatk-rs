GATK LoglessPairHMM — linear-space DP, log10 only on the final sum. Observable Java contract (LoglessPairHMM.subComputeReadLikelihoodGivenHaplotypeLog10): INITIAL_CONDITION = 2^1020; free leading deletions = INITIAL / haplen. Match/Ins/Del updates multiply (not log-sum); priors use qualToProb / qualToErrorProb/3. Result = log10(sum last-row M+I) − log10(INITIAL_CONDITION). This is the scalar reference for SIMD kernels. Exact Log10PairHMM remains in crate::pairhmm_log10 for F.1/F.2 bit-identical dumps.

Constants§

INITIAL_CONDITION
2^1020 — GATK LoglessPairHMM.INITIAL_CONDITION (IEEE bits of ldexp(1, 1020)). Do not replace with a rounded decimal literal — a prior 1.07…e307 was ~4.6% low.
INITIAL_CONDITION_LOG10
log10(2^1020) = 1020 · log10(2). A prior literal 307.652… was high by log10(4) and shifted every logless score by ≈ −0.602 vs Log10PairHMM.
MIN_ACCEPTED_LINEAR_SUM
GKL-style underflow threshold for f32→f64 retry (linear-space final sum before log10).
