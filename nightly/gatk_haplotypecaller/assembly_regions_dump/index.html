Module assembly_regions_dump 

Source
Expand description

Dense smoothed activity profile export for parity with GATK HaplotypeCaller --assembly-region-out. Walks every 1-based position in -L, builds per-locus pileups, feeds BandPassActivityProfile, then writes position\\tactive_prob (smoothed) for comparison to the Java IGV derivative.
