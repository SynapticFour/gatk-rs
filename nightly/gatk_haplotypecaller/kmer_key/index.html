Compact k-mer keys for read-threading graphs.

§Observable contract

Encoding is an internal acceleration only. Topology, multiplicity, and haplotype bases must match the historical Arc<[u8]> builder. Ambiguous bases (N / non-ACGT) and k > 64 keep byte-slice identity.

§Packed layout

Pure ACGT windows pack 2 bits/base MSB-first so lexicographic ACGT order equals numeric order (useful if adaptive pruning ties compare keys).
