GATK4 AssemblyRegionWalker–style read sharding. See docs/ARCHITECTURE.md. Mirrors the first step of AssemblyRegionWalker.makeReadShards: group user intervals by contig, merge overlaps on the input grid, then expand each span by assemblyRegionPadding (default 100 bp per side, matching AssemblyRegionArgumentCollection.DEFAULT_ASSEMBLY_REGION_PADDING in GATK 4.x). B.2: region stream over each padded span lives in crate::assembly_region_iterator (AssemblyRegionIterator). B.3: apply vs callRegion disposition — crate::walker_apply and crate::HaplotypeCallerEngine::walker_apply_stats.
