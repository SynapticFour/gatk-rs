HaplotypeCaller

Call germline SNPs and indels via local re-assembly of haplotypes Default: assembly-region-v1 emits variants via full call_region. Set GATK_RS_HC_SCAFFOLD_OUTPUT=1 for header-only scaffold.

Fields

§reference: String

Reference genome FASTA (GATK: -R)

§input: Vec<String>

Input BAM/SAM (GATK: -I; repeat for multiple inputs)

§output: String

Output VCF (GATK: -O)

§intervals: Vec<String>

Genomic intervals (GATK: -L; repeatable, same as Java GATK)

§output_mode: String

Variant calling output mode: VCF | GVCF | BP_RESOLUTION (GATK: --output-mode / -mode)

§min_base_quality_score: u8

Minimum base quality (GATK: --min-base-quality-score)

§emit_ref_confidence: Option<String>

Emit reference confidence: NONE | GVCF | BP_RESOLUTION (GATK: --emit-ref-confidence; native GATK also documents -ERC, which is not expressible as a single clap short flag — use the long form here).

§pair_hmm: Option<String>

PairHMM implementation (GATK: --pair-hmm-implementation): LOG10_PAIRHMM (default) | LOGLESS_HMM | AVX/SIMD | SIMD_F32 | FASTEST_AVAILABLE. Alias: --pairhmm-impl scalar|logless|simd|fastest.

§original_base_qualities: bool

Use original base qualities

§dont_use_soft_clipped_bases: bool

Don’t use soft clipped bases

§max_alternate_alleles: u32

Maximum number of alternative haplotypes (not wired — Java default 6 always used)

§min_mapping_quality: u32

Minimum mapping quality (GATK: --min-mapping-quality)

§stand_call_confidence: f64

Minimum phred-scaled confidence to call variants (GATK: --standard-min-confidence-threshold-for-calling)

§stand_emit_confidence: f64

Minimum phred-scaled confidence to emit variants (GATK: --standard-min-confidence-threshold-for-emitting)

§alleles: Option<String>

VCF of alleles to force into assembly (GATK: -alleles / --alleles)

§threads: Option<usize>

Worker threads for Active-Region / PairHMM parallelism (GATK-shaped --threads / -nt). Default: number of logical CPUs. 0 also means auto-detect. When set, wins over ambient RAYON_NUM_THREADS.

CombineGvcfs

Combine per-sample gVCFs into a multi-sample gVCF (no joint genotyping). Merges reference-confidence blocks and remaps PL/AD onto a unified allele set (GATK CombineGVCFs algorithm). GenotypeGVCFs is a separate step.

Fields

§reference: String

Reference genome FASTA (GATK: -R)

§variant: Vec<String>

Input gVCF(s); repeat -V once per sample (GATK: -V)

§output: String

Output combined gVCF (GATK: -O)

§intervals: Vec<String>

Optional intervals (GATK: -L; repeatable)

§

VariantFiltration

Hard-filter variants with GATK-style filter expressions (not VQSR). Soft-filters by writing FILTER tags. Does not replace VQSR algorithmically it is the pragmatic fallback for smaller cohorts where VQSR cannot be trained cleanly (aligned with official GATK Best Practices guidance). Prefer one annotation per --filter-expression (GATK recommendation). Use --preset snp or --preset indel for the official hard-filter tables, or pass explicit --filter-expression / --filter-name pairs (Java GATK CLI compatible).

Fields

§variant: String

Input VCF (GATK: -V)

§output: String

Output VCF (GATK: -O)

§reference: Option<String>

Optional reference (accepted for GATK familiarity; unused for hard filters)

§filter_expression: Vec<String>

Filter expression on INFO/QUAL (repeatable; GATK: --filter-expression / -filter)

§filter_name: Vec<String>

Name written to FILTER when the paired expression fails (repeatable)

§preset: Option<String>

Apply official GATK hard-filter table: snp or indel (merged with any explicit –filter-expression pairs)

GenotypeGvcfs

Joint-genotype a multi-sample gVCF into a final cohort VCF. Uses cohort allele-frequency EM over sample PLs (GATK GenotypeGVCFs).

Fields

§reference: String

Reference genome FASTA (GATK: -R)

§variant: String

Combined multi-sample gVCF (GATK: -V)

§output: String

Output cohort VCF (GATK: -O)

§intervals: Vec<String>

Optional intervals (GATK: -L; repeatable)

§stand_call_conf: f64

Minimum QUAL to emit (GATK: --standard-min-confidence-threshold-for-calling)
