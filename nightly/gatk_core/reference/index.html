ReferenceWindowCache
Contig-level reference cache (R4-1): load each contig once (via .fai when present), serve windows by slice. Contig bytes are retained in a process-wide Arc map so short-lived caches (per callRegion) do not re-read the FASTA. Local eviction drops the smallest contig name (BTreeMap order).
SequenceDictionary
Sequence dictionary derived from reference metadata.
