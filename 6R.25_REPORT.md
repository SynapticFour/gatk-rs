## 1. VERDICT

**Class C1 — reference-representation divergence confirmed.**

On the canonical mid-B ActiveFull region, uniqueness and graph construction depend on which reference bytes are presented:

| Reference | Length | k=10 unique | k=25 unique | k=25 graph built |
|---|---|---|---|---|
| Java-equivalent `refHaplotype` (extended span) | **430** | false | **true** | **true** |
| Production `assembly_reference_read` (±500 pad) | **1430** | false | **false** | **false** |

With the 430 bp Java-equivalent reference, Rust k=25 SeqGraph assembly produces **430M haplotypes**, including an ALT that carries

`92317399 C/A`, `92317407 T/C`, `92317412 G/C`.

Production EventMap on that ALT set emits those three sites. Production assembly on the 1430 bp padded REF does **not** enter k=25 and does **not** emit C/A.

**No production code was changed.**
