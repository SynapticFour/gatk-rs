# Java-side L2 dumps (pinned GATK)

Frozen TSV artifacts produced by [`HcFullParityGateDump.java`](../../../../scripts/parity/java/HcFullParityGateDump.java) against the pin in [`docs/GATK_PINNED.env`](../../../../docs/GATK_PINNED.env).

Subcommand ↔ phase mapping: [`HC_FULL_PARITY_L2_EMITTER_MATRIX.md`](../../../../scripts/parity/README.md).

```
java_dumps/
  b1/<case_id>_<PIN>.tsv
  b2/...

  d2/...
  d3/...
  e1/... e7/...
  f1/...
```


`<PIN>` = short SHA (currently **`2dbc0258`**).

## Regenerate

```bash
./scripts/parity/run_hc_full_parity_java_refresh.sh
```

## Compare (Rust vs Java)

```bash
./scripts/parity/run_hc_full_parity_l2.sh
```

**Default is strict** (exit non-zero on mismatch; CI runs this via `checks.json` → **hc-full-parity-l2-strict**). Set `PARITY_HC_FULL_L2_STRICT=0` for advisory runs only.

## Schema

Same columns as Rust `hc_full_parity_gate_dump` for each phase (see phase `README.md` under `b1/`, `b2/`, …).
